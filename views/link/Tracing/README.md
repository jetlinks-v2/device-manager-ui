# 集群链路查询

统一入口为 `/infrastructure/runtime-monitor?view=tracing`；仅有 Tracing 菜单授权时沿用 `/infrastructure/tracing`。旧 tracing 深链在同时具有 RuntimeMonitor 菜单时保留 Trace / Span / 节点定位并迁移到统一入口，使用 `TracingController` 按 Trace ID 查询，不按节点拆分链路。`useClusterTrace.ts` 负责权限、授权节点目录、路由和运行监控联动；`useTraceWorkspace.ts` 负责有界查询工作区，`store/traceWorkspace.ts` 持有本次跨页排查会话；展示复用 web-core 的 `TraceViewer`。

查询接受非零 32 位十六进制 Trace ID 或完整的 W3C version 00 `traceparent`，支持粘贴 `traceparent: ...` 标头行并归一化大小写。浏览器将多个响应头合并为逗号分隔值时，只有各项均为完整合法上下文且属于同一 Trace ID 才查询；Span ID 和标志位可以不同，不同链路、空项或内部换行不猜测取首项。非法、零值或不完整的上下文在本地提示，不发请求；不从任意日志文本中截取 ID。输入下方按需展开 Chrome DevTools 风格的 Network → 请求 → Headers → Response Headers 示意，三个编号对应获取位置；设备消息展示 `headers.traceparent`，访问日志展示 Trace ID。图示明确使用合成数据，不提供复制虚构标识或查询示例的动作；用户应复制实际请求、消息或日志中的值。格式说明、Span ID 区别和缺失原因按需展开；帮助同时只打开一个来源，可用关闭按钮或 Escape 收起，长内容在视口内滚动。

工作区最多保留 8 个标签。多结果页签采用正文内 32px Ant 可编辑次级导航，负责关闭、新增、键盘和溢出；外层运行监控工作区独占 PageChrome 与 SlantedTabs 一级导航。相同 ID 再次查询只激活已有标签；`+` 打开唯一空查询标签。每条链路独立保留数据、加载或错误状态、选中 Span、搜索、折叠和表格双轴滚动位置，切换标签不重新请求。标题取入口 Span，缺失根节点时取最早有效 Span；只有明确的 `/http/METHOD/path` 标准方法名简化为 `METHOD /path`，合法路径编码转为可读文字，坏编码或控制字符降级原文；其他命名保持原样。名称旁常驻短 Trace ID 后缀，默认 8 位，当前标签有后缀冲突时逐步延长；完整名称和 ID 保留在标题提示中。关闭标签取消其请求，关闭活动标签后切换相邻标签，关闭最后一个标签回到查询入口。错误结果可重试，容量已满时提示先关闭标签。

URL 的 `traceId`、`span`、`nodeId` 定位当前链路；兼容日志跳转携带的 `spanId`。日志跳转使用 `logFrom/logTo` 传递毫秒起止时间，避免与平台登录的 `from` 参数冲突；日志页格式化显示有效范围，非法、倒序或有歧义的范围不展示。离开页面取消未完成请求但保留内存中的全部对比标签、结果与选中 Span；返回后依 URL 激活对应标签，仅恢复该标签尚未完成的查询。页面卸载后，账号、项目或读取权限变化仍会同步取消并清空会话，过期响应不能回写。浏览器刷新只恢复 URL 中的当前链路，不持久化诊断正文。

缓存页面只有在当前路由属于链路追踪时才响应查询参数或同步 URL；停用页面不得改写其他页面的节点、工具或链路参数。刷新当前链路期间保留已有数据和局部浏览状态；服务明确拒绝读取时清除该链路的数据。

一级切换保留各视图的 query 与 ContentPanel 滚动快照；Trace 结果组件保持挂载，隐藏视图暂停请求和图表活动，返回后仅恢复活动标签的未完成查询。没有标签或没有读取授权时不展示结果导航。Span 的 `app` 只与授权节点目录精确匹配；未知来源仍保留原值，不猜测为节点。日志和节点跳转在执行时再次校验权限与当前链路中的节点身份。

耗时按纳秒差值计算并使用同一时间轴；长条内部显示耗时，短条优先在轨道内的条后或条前空位显示，两侧都不足时分层显示，不为文字拉长短条。悬停或键盘聚焦时间轴可读取包含子调用的格式化耗时、精确纳秒及相对起点，选中后在行内详情查看。“下一异常”独立定位明确的异常事件；“慢调用”按精确耗时降序循环定位已挂接且正耗时的子调用，同耗时保留树顺序，不把入口或孤儿根列为慢点。该入口用于排查，不推导自身耗时、慢阈值或瓶颈；无可比较子调用时禁用并提示，单个调用仍可点击行查看详情。定位会展开祖先，保留搜索、其他折叠和各标签的浏览状态。节点旁按真实字段提供最多三个证据入口：`exception` 事件、平台 `sql` 或标准数据库语句、已识别的 HTTP 状态；`flux-next-count` 仅在值为非负安全整数时提供输出项数。未知信息只展示属性与事件数量，不根据名称或任意字符串推测错误。

属性按静态小标题分组，识别平台裸 `sql` 为数据库证据，HTTP 根 Span 不补造状态码。普通选中按异常、SQL、HTTP、普通属性的优先级直达证据；点击证据入口一次即可选中并定位对应内容。异常入口同时展示摘要和首个可用堆栈，详情正文与长代码有界滚动，技术 ID 单独折叠。

选中行与其展开详情共用连续的弱背景，取消二者之间的分隔线；详情正文起点与所在行的调用名、节点文字对齐，使用同一树缩进和折叠按钮轨道。展开内容不另套卡片，横向滚动时保持在当前表格可视宽度内，技术信息折叠区也沿用正文起点。

Span 调用名保持单行省略并保留完整提示，节点为常用服务名及端口预留宽度。节点旁以一组图标短摘要展示动作 `request.action`、操作者 `user.name` / `user.username`（合并去重）及来源 `request.ip`（缺失时接受 `client.address` / `net.peer.ip`），并合并证据入口，异常优先。一行优先显示，窄屏按入口折行，不整行裁切；平台“资源-动作”或多级资源前缀文本简写为末段动作，缺失段和其他名称保留原样，操作者优先显示姓名。完整账号、动作及证据在提示与辅助标签中保留，点击可直达原始字段。缺失字段省略，该摘要不提升 `user.id`、凭证或未知原文。属性详情统一使用紧凑的键列与值列，窄容器改为单列；长文本、多行及结构化值可原位展开并复制完整内容。
