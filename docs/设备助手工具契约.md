# 设备助手工具契约

`device-manager-ui` 只负责设备领域的参数、权限、查询和结果语义；跨工具失败格式使用 `@jetlinks-web-core` 公共契约，不依赖智能体 UI 或其他业务模块。

## 会话能力与工具收敛

两个设备详情入口复用 `deviceDetailAgent.parameters.ts` 的会话参数，使用既有分组覆盖关闭 `media`、`validate`；保留 `document`（PDF 导出）、`fs`、`chart`、`dataset` 和部署已选的其他能力，不改共享部署智能体，不按用户句式选工具。参数只收紧，不用另一份允许列表重新开启部署已关闭的组；`validate` 组开关不影响参数、权限或结果契约校验。

物模型读取统一使用 `device_model_get` 的格式选择，旧详情入口支持有界 inline 结果及按需完整 Markdown/JSON 模型文件，移除重复暴露的 `device_metadata_markdown`。`createDeviceModelGetTool` 通过 `fileOutput` 显式选择可选的已写入文件引用，不改变其他调用方的默认输出；路径与 URI 复用会话文件接口回执，不引入新的 artifact 物化协议。属性快照/主动读取、汇总/明细、边端/会话文件保持独立。三个运行指标暂保持独立：现有 analytical producer 的单一输出契约与各指标的不同单位不宜为减少两个名称而扩大 core 协议；CSV 专用便利入口的兼容退役另行评估。

实现入口：`views/device/list/agent/`、`views/device/Instance/Detail/clientTools.ts`、`views/device/agentTools/devicePropertyAnalysisTools.ts`。`views/device/Instance/Detail/Child/index.vue` 在关闭未保存编辑确认框时用 `next(false)` 终止导航，保留当前编辑状态。没有新增智能体 UI 或其他业务模块依赖。

## 页面能力与统计口径

时间语义由 `agentCapabilities/deviceAnalysis/deviceAnalysis.shared.ts/mapDeviceTimeContext` 统一提供：lastSeen 是最近活动/连接状态时间，不是上报时间；onlineAt/offlineAt 是各自连接事件，lastReportAt 缺失表示未知。`views/device/list/services/adapters/iotDeviceApiAdapter.ts` 选择较晚的上下线事件，上报时间仅映射实例已有的 lastReportTime 或同设备回退值，不用当前时间或另一设备的回退值制造事实。`views/device/list/hooks/useIotDeviceDetailView.ts#mergeRealtimePropertyValue` 用实际订阅时间更新页面 lastReportAt；初次加载属性快照的 `loadRealtimePropertySnapshot` 当前未汇总该字段，不由连接时间推断上报缺失。

实施入口：`views/device/list/agent/useDeviceDetailAgent.ts`、`DeviceDetailAgentHost.vue` 与 `agentCapabilities/deviceAnalysis/devicePropertyAggregate.support.ts` / `deviceProperty.service.ts`。嵌入页面提供自身实际 tabs/defaultTab，工具 schema、导航和提示使用同一声明，不按外部模块路由名推断。属性聚合增加可选 aggregates，多统计量合入一次标量聚合查询并保留各自输出字段，复杂属性仍沿用既有有界历史查询；已有单一 agg 调用保持兼容。同一属性请求多个统计量时，缺失别名不得回退到未标明统计口径的属性值。图表与正文复用原始结果，空结果和分桶统计不能扩张为全时段健康或原始峰值判断。

既有上下文陈旧风险：`useDeviceDetailAgent.ts#queryWithDevice` 将初始设备对象交给 `deviceDetailDiagnostics.service.ts`，同设备、同页签时复用服务；页面刷新或订阅替换设备对象后，`device_context_get` 可能仍返回旧时间与状态，不能保证活跃会话持续同步。正文将未定义属性推断为未接传感器、将部分快照扩大为全部上报结论，以及缺失点解释和忽略当前问题的风险仍未闭环。

## 缺少查询主体

收敛范围：物模型读取与搜索、设备属性最新值与历史、共享属性聚合工具。保持现有 ID 归一化和权限检查顺序，不改变正常查询。

- 物模型工具要求实际 `deviceId` 或 `productId`；设备运行数据工具要求实际 `deviceId`。
- 缺参错误使用 `failureDisposition=request`、`recoveryAction=repair`、`retryable=false`；调用方先补齐参数，不应重复发送原请求。
- 修复元数据描述必需输入，修复预算为一次；不判断页面、模型、关键词或其他模块的工具名。
- 错误文案沿用调用方已有 i18n 文案，不在失败消息中夹带编排提示词。

实现入口：`views/device/Domain/agentDeviceDomainTools.ts`、`views/device/agentTools/propertyAggregateTool.ts`；错误契约收敛于 `views/device/agentTools/deviceSubjectContract.ts`。

验证范围：实际工具缺参调用、ID 归一化、权限检查优先级和共享运行时失败序列化，由下述工具测试覆盖；现有基线类型问题不在本次修复范围。
